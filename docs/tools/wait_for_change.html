Wait for Screen Change

wait_for_change

Wait until part of the screen changes or settles, instead of guessing a sleep. Returns the elapsed time, changed regions (screenshot pixels; add origin for desktop), and the final state.

watchread-onlyidempotentsince v0.18.0

00:00PARAMETERS
NameTypeDescription
target requiredstringWhat to watch: full | monitor:<i> | window:<title> (or exe=/hwnd=) | region:<x>,<y>,<w>,<h>.
exactTitlebooleanwindow: targets match the whole title only (default false).
mode"change" | "settle"change (default): return once it differs from the start. settle: once it has been still for settleSec.
timeoutSecnumberGive up after this many seconds (default 30; a timeout is a result, not an error). > 0, ≤ 600
settleSecnumberMode settle: seconds of stillness (default 1). > 0, ≤ 60
intervalMsintegerPause between checks in ms (default 250). ≥ 100, ≤ 5000
pixelThresholdnumberMean 0-255 difference for a ~32x32 cell to count as changed (default 12). ≥ 0, ≤ 255
returnImagebooleanReturn the final state inline (default true).
keepbooleanKeep the final screenshot on disk and return its path (default false).
