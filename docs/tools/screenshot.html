SCREENCAST-MCP / TOOLS / CAPTURE

Take Screenshot

screenshot

Capture one PNG of the screen, a monitor, a window, or a region, returned inline and by path.

capturewritesdestructivesince v0.2.0

00:00PARAMETERS
NameTypeDescription
target requiredstringfull | monitor:<i> (0 = primary) | window:<title> (or window:exe=<app.exe> / window:hwnd=<n>) | region:<x>,<y>,<w>,<h>. Titles match exactly, else as a substring; topmost wins.
exactTitlebooleanwindow: targets match the whole title only, never a substring (default false).
backend"gdigrab" | "wgc"gdigrab (default, ~0.2 s): what is visible. wgc (window:, FFmpeg 8+, ~1-2 s): the window even if covered.
outputstringOptional output .png path. Defaults to a file under SCREENCAST_HOME/screenshots.
overwritebooleanAllow replacing an existing file at the output path (default false).
returnImagebooleanReturn the image inline (default true; the PNG on disk stays full size).
maxImageWidthintegerMax inline image width (default 1280). ≥ 16, ≤ 9007199254740991
