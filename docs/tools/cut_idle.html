Cut Idle Stretches

cut_idle

Remove dead air: cut stretches where the screen is frozen (and silent), keeping a short pad. Returns the time saved.

editwritesdestructivesince v0.26.0

00:00PARAMETERS
NameTypeDescription
input requiredstringPath to the source video.
minIdleSecnumberOnly cut still stretches at least this long (default 2). > 0
keepSecnumberSeconds kept at each edge of a cut (default 0.4). ≥ 0
useAudiobooleanRequire silent audio too (default true when there is audio).
dryRunbooleanOnly report what would be cut.
outputstringOptional output path. Defaults under SCREENCAST_HOME/edits.
overwritebooleanAllow replacing an existing file at the output path (default false).
00:05A MINIMAL CALL
cut_idle { "input": "recording.mp4" }

The required arguments only, with placeholder values. Everything else takes its default.

00:10WHAT COMES BACK

A text result; this tool declares no structured output.
