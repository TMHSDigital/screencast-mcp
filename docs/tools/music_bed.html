Add Music Bed

music_bed

Lay music under a video: looped or trimmed to length, faded, leveled, and mixed with any existing audio. Video is stream-copied.

audiowritesdestructivesince v0.7.0

00:00PARAMETERS
NameTypeDescription
video requiredstringPath to the video.
music requiredstringMusic audio file.
musicVolumenumber0..1 (default 0.25 over existing audio, 0.8 alone). ≥ 0
fadeInnumberFade-in seconds (default 1). ≥ 0
fadeOutnumberFade-out seconds (default 2). ≥ 0
duckbooleanDuck the music under the original audio (default false).
outputstringOptional output path. Defaults under SCREENCAST_HOME/edits.
overwritebooleanAllow replacing an existing file at the output path (default false).
00:05A MINIMAL CALL
music_bed { "video": "recording.mp4", "music": "music.mp3" }

The required arguments only, with placeholder values. Everything else takes its default.
