SCREENCAST-MCP / TOOLS / PRODUCE

Zoom and Pan

zoom

Smooth animated zoom-and-pan into the action and back out, from keyframes or planned from logged clicks or screen changes.

producewritesdestructivesince v0.27.0

00:00PARAMETERS
NameTypeDescription
input requiredstringPath to the source video.
keyframesobject[]Views reached by time t: a source rectangle (x, y, width, height), or { t, full: true } to zoom out. Omit to plan them (see follow). at most 100 items
keyframes[].t requirednumber ≥ 0
keyframes[].xnumber
keyframes[].ynumber
keyframes[].widthnumber > 0
keyframes[].heightnumber > 0
keyframes[].fullboolean
follow"auto" | "clicks" | "changes"Without keyframes: clicks (from the events log of start_recording events: true) or changes (where the screen changed). auto (default): clicks if logged, else changes.
eventsstringEvents log (default: the input's .events.jsonl); must match the input's timing and size, so use the original recording.
highlightClicksbooleanRing each logged click (default false).
highlightColorstringRing color (default #FF4545).
transitionSecnumberHow long each zoom/pan eases (default 0.6). > 0, ≤ 5
maxZoomnumberAuto mode: the furthest it zooms in (default 2.5). ≥ 1, ≤ 6
holdSecnumberAuto mode: stay zoomed this long after activity (default 2). > 0, ≤ 30
dryRunbooleanReturn the planned keyframes only (editable, pass back).
outputstringOptional output path. Defaults under SCREENCAST_HOME/edits.
overwritebooleanAllow replacing an existing file at the output path (default false).
00:05A MINIMAL CALL
zoom { "input": "recording.mp4" }

The required arguments only, with placeholder values. Everything else takes its default.
