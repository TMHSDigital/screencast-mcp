Denoise Audio

denoise

Reduce steady background noise (fan, hum, hiss) in a recording's audio with an adaptive FFT denoiser. Video is copied untouched. Returns the output path.

audiowritesdestructivesince v0.22.0

00:00PARAMETERS
NameTypeDescription
input requiredstringPath to the source video or audio file.
strength"light" | "medium" | "strong"How hard to reduce noise: light (6 dB), medium (12 dB, default), strong (20 dB).
outputstringOptional output path. Defaults under SCREENCAST_HOME/edits.
overwritebooleanAllow replacing an existing file at the output path (default false).
