SCREENCAST-MCP / TOOLS / AUDIO

Transcribe Speech

transcribe

Transcribe a recording's speech to an SRT subtitle file, locally, with FFmpeg 8's whisper filter (needs a whisper.cpp model file). Returns the SRT path and the text. Pair with burn_subtitles to caption the video.

audiowritesdestructivesince v0.25.0

00:00PARAMETERS
NameTypeDescription
input requiredstringPath to the video or audio to transcribe.
modelstringPath to a whisper.cpp model file (ggml-*.bin). Defaults to SCREENCAST_WHISPER_MODEL.
languagestringSpoken language code, e.g. 'en', or 'auto' (default).
wordsbooleanOne word per cue, for word timing (cut_by_transcript).
outputstringOptional output .srt path. Defaults under SCREENCAST_HOME/edits.
overwritebooleanAllow replacing an existing file at the output path (default false).
00:05A MINIMAL CALL
transcribe { "input": "recording.mp4" }

The required arguments only, with placeholder values. Everything else takes its default.
