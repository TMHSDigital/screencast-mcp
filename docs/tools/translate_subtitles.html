Translate Subtitles

translate_subtitles

Translate an SRT without breaking its timing: call once for the numbered cues, translate them, then call with translations to write <input>.<language>.srt for chapters' subtitleTracks.

producewritesdestructivesince next release

00:00PARAMETERS
NameTypeDescription
input requiredstringThe .srt to translate (e.g. from transcribe).
languagestringWith translations: ISO 639-2 code, e.g. "spa".
translationsstring[]One translated string per cue, in order. Omit to get the cues to translate. at most 2000 items
outputstringDefault: <input>.<language>.srt.
overwritebooleanReplace an existing output (default false).
00:05A MINIMAL CALL
translate_subtitles { "input": "recording.mp4" }

The required arguments only, with placeholder values. Everything else takes its default.

00:10WHAT COMES BACK

A text result; this tool declares no structured output.
