SCREENCAST-MCP / TOOLS / EDIT

Extract Clips

clip

Extract several frame-exact segments, each to its own file. For one segment, trim does the same.

editwritesdestructivesince v0.3.0

00:00PARAMETERS
NameTypeDescription
input requiredstringPath to the source video.
segments requiredobject[]{start, end} segments in seconds; each becomes its own file. at least 1 items
segments[].start requirednumber ≥ 0
segments[].end requirednumber > 0
outputstringOptional output path. Only honored for a single segment; multi-segment output lands under SCREENCAST_HOME/edits.
overwritebooleanAllow replacing an existing file at the output path (default false).
00:05A MINIMAL CALL
clip { "input": "recording.mp4", "segments": [{"start": 0, "end": 1}] }

The required arguments only, with placeholder values. Everything else takes its default.
