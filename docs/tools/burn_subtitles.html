Burn In Subtitles

burn_subtitles

Burn SRT/ASS subtitles (e.g. from transcribe) into a video in the bundled font.

producewritesdestructivesince v0.25.0

00:00PARAMETERS
NameTypeDescription
input requiredstringPath to the source video.
subtitles requiredstringPath to an .srt (e.g. from transcribe) or .ass subtitle file.
style"clean" | "social"clean (default for .srt): outlined line. social: big bold text on a dark box. .ass keeps its own styling unless set.
outputstringOptional output path. Defaults under SCREENCAST_HOME/edits.
overwritebooleanAllow replacing an existing file at the output path (default false).
00:05A MINIMAL CALL
burn_subtitles { "input": "recording.mp4", "subtitles": "captions.srt" }

The required arguments only, with placeholder values. Everything else takes its default.
