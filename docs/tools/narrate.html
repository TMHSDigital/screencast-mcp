SCREENCAST-MCP / TOOLS / AUDIO

Narrate

narrate

Offline voiceover with the built-in Windows voices: speaks each line at its time or marker over the audio, plus an SRT.

audiowritesdestructivesince v0.47.0

00:00PARAMETERS
NameTypeDescription

lines[].markerstringOr a marker label.
lines[].text requiredstring
voicestringVoice name or part (doctor lists them).

duckbooleanDuck the original audio (default true).

00:05A MINIMAL CALL
narrate { "video": "recording.mp4", "lines": [{"text": "Save"}] }

The required arguments only, with placeholder values. Everything else takes its default.
