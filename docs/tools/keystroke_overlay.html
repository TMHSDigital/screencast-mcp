SCREENCAST-MCP / TOOLS / PRODUCE

Keystroke Overlay

keystroke_overlay

Burn keycast-style badges for shortcuts, clicks, and typing from the recording's input event log (start_recording events: true). Never shows typed text: the log has none.

producewritesdestructivesince v0.45.0

00:00PARAMETERS
NameTypeDescription
input requiredstringPath to the recording.
eventsstringEvent log (default: the input's .events.jsonl).
clicksbooleanShow clicks (default true).
typingbooleanShow typing as "Typing…" (default true).
keys"shortcuts" | "masked"shortcuts (default): the chord (Ctrl + S); masked: modifiers only (Ctrl + …).
lingerSecnumberSeconds a badge stays up (default 1.2). > 0, ≤ 10
position"bottom" | "bottom-left" | "bottom-right" | "top" | "top-left" | "top-right"Default bottom (centred).
sizenumberFont px (default 4.5% of the frame height). ≥ 8, ≤ 400
colorstringText color (default white).
fontFilestringFont: a .ttf/.otf/.ttc path or a C:\Windows\Fonts file name. Default: bundled Inter, with a covering system font for scripts it lacks (CJK, emoji, Arabic, ...).
dryRunbooleanReturn the planned badges; write nothing.
outputstringOptional output path. Defaults under SCREENCAST_HOME/edits.
overwritebooleanAllow replacing an existing file at the output path (default false).
00:05A MINIMAL CALL
