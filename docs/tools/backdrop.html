Add Backdrop

backdrop

Frame a video or screenshot on a gradient, color, or wallpaper with padding, rounded corners, and a drop shadow, optionally on a 16:9/1:1/9:16/4:5 canvas.

producewritesdestructivesince v0.45.0

00:00PARAMETERS
NameTypeDescription
input requiredstringPath to the source video or image (png/jpg).
preset"desktop" | "rec" | "amber" | "light"Gradient: desktop (default, dark slate), rec (red), amber, light.
colorsstring[]Instead: 1 color = solid, 2-4 = diagonal gradient. at least 1 items, at most 4 items
imagestringInstead: a wallpaper image, scaled to cover.
paddingintegerpx around the content (default 6% of the longer side). ≥ 0, ≤ 2000
radiusintegerCorner radius px (default ~1.2% of the longer side; 0 = square). ≥ 0, ≤ 1000
shadowintegerShadow blur px (default ~2.5%; 0 = none). ≥ 0, ≤ 200
shadowOpacitynumberDefault 0.5. ≥ 0, ≤ 1
aspect"16:9" | "9:16" | "1:1" | "4:5"Output on this aspect's canvas (1920x1080, ...), content scaled to fit.
outputstringOptional output path. Defaults under SCREENCAST_HOME/edits (screenshots for an image).
overwritebooleanAllow replacing an existing file at the output path (default false).
00:05A MINIMAL CALL
backdrop { "input": "before.png" }

The required arguments only, with placeholder values. Everything else takes its default.
