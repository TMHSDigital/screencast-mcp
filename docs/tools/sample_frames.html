SCREENCAST-MCP / TOOLS / WATCH

Sample Frames

sample_frames

Sample PNG frames from a video (by fps, timestamps, or scene changes) and return the first few inline so the model can see what happened.

watchread-onlyidempotentsince v0.2.0

00:00PARAMETERS
NameTypeDescription
input requiredstringPath to the source video file.
mode"fps" | "timestamps" | "scenes"scenes: only frames where the screen changed (strongest first), usually the cheapest review. Default: fps or timestamps, whichever is given.
fpsnumberFrames per second (mode fps). > 0
timestampsnumber[]Seconds to grab a frame at (mode timestamps).
sceneThresholdnumberMode scenes: change needed to count, 0-1 (default 0.1). > 0, < 1
dedupebooleanMode fps: drop near-duplicate frames (default false).
outputDirstringOptional folder for the frames (a relative path resolves under SCREENCAST_HOME/frames). Defaults to SCREENCAST_HOME/frames/<id>.
maxFramesintegerFrame cap (default 100); fps is lowered to fit while still spanning the video. ≥ 1, ≤ 1000
returnImagesbooleanReturn the first maxInlineImages frames inline (default true).
maxInlineImagesintegerFrames to embed inline (default 8); all are listed by path. ≥ 0, ≤ 20
maxImageWidthintegerMax inline image width (default 1280). ≥ 16, ≤ 9007199254740991
