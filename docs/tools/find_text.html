Find Text (OCR)

find_text

OCR (built into Windows) on the screen, an image, or video frames, with line and match boxes in image pixels (add origin for desktop coordinates). Locate UI text or secrets (e.g. regex 'sk-|ghp_|api.?key') to redact. Best-effort: review results.

watchread-onlyidempotentsince v0.19.0

NameTypeDescription

inputstringImage or video file to read instead of a live target.

maxFramesintegerscanEverySec frame cap (default 30; ~1 s each). ≥ 1, ≤ 120

backend"gdigrab" | "wgc"Live target: gdigrab (default) = what is visible; wgc (window:, FFmpeg 8+) = the window even if covered.
querystringText to find (case-insensitive, tolerates OCR misreads like I/l, O/0, _/-). Omit to return all text.
regexbooleanTreat query as a regular expression (case-insensitive).
redactbooleanAlso return padded match rectangles ready for redact_region's regions.
keepbooleanLive target: keep the capture and return its path (default false: deleted after reading).
returnImagebooleanReturn the image with matches outlined (default: true with a query).
