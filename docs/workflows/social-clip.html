SCREENCAST-MCP / WORKFLOWS / REC 04

Social clip

Screen recordings are landscape; short-form feeds are vertical. The agent re-aspects the recording, puts a title card in front, crossfades the two, lays music under it at a sane level, normalizes loudness, and encodes for the platform.

00:00THE PROMPT

Make a TikTok from the demo recording: 9:16 with the window letterboxed, a 1.5 s title card that says “Saving, fixed”, a fade into the clip, and this music under it.

00:05THE CALLS IT MAKES

reframe → title_card → assemble_highlights → music_bed → normalize_audio → export_preset. Paths are shortened; every value is from a real run.

  1. reframe { "input": "rec-….mp4", "aspect": "9:16", "fit": "pad" }pad letterboxes and keeps the whole window; crop fills the frame and loses the sides.{ "outputPath": "reframe-….mp4" }
  2. title_card { "text": "Saving, fixed", "duration": 1.5, "width": 1080, "height": 1920 }{ "outputPath": "title-….mp4" }
  3. assemble_highlights { "clips": ["title-….mp4", "reframe-….mp4"], "transition": "fade", "width": 1080, "height": 1920 }Normalizes size, fps, and audio first, so mixed clips join cleanly.{ "clips": 2, "transition": "fade" }
  4. music_bed { "video": "highlights-….mp4", "music": "music.wav", "musicVolume": 0.3 }Loops or trims the track to the video and fades it in and out.{ "mixedWithOriginal": true }
  5. normalize_audio { "input": "music-….mp4", "target": "youtube" }Two-pass loudnorm to −14 LUFS, the level most feeds normalize to anyway.{ "before": { "lufs": -41.59 }, "after": { "lufs": -14.05 } }
  6. export_preset { "input": "loudnorm-….mp4", "platform": "tiktok" }{ "aspect": "9:16", "fps": 30 }
00:30THE OUTPUT

Swap platform for youtube, instagram_reel, x, or square. Have narration? Run transcribe and burn_subtitles with style: "social" before the export: most feeds autoplay muted.
