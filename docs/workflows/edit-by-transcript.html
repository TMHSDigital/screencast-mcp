SCREENCAST-MCP / WORKFLOWS / REC 08

Edit by the transcript

Narration is where most of the editing time goes: the false start, the "um", the closing line you'd rather not keep. Transcribe with word timing, then cut by quoting the words. Audio and video are cut in the same pass, so they stay in sync, and the transcript comes back re-timed to the new video.

00:00THE PROMPT

Transcribe my narrated demo, take out the ums and uhs and the last sentence, and keep the captions lined up.

00:05THE CALLS IT MAKES

transcribe (words) → cut_by_transcript (dryRun) → cut_by_transcript → burn_subtitles. Paths are shortened; every value is from a real run.

  1. transcribe { "input": "demo.mp4", "words": true }words: true asks whisper for one word per cue (max_len=1), so every word has its own timestamps. Without it, cues are sentences, and a cut inside one is an estimate.{ "srtPath": "captions-….srt", "cues": 24, "text": "Hello and welcome to this demo. Um. Today we will open the Settings page. uh, then we click save. That is all for now." }
  2. cut_by_transcript { "input": "demo.mp4", "srt": "captions-….srt", "fillers": true, "remove": ["that is all for now"], "dryRun": true }A quote is matched ignoring case and punctuation, and must occur exactly once (otherwise quote more words, or pass cue numbers). Fillers take the pause around them, up to 0.5 s a side. dryRun returns the edited text to check first.{ "cuts": [{ "start": 2, "end": 3.271, "text": "Um.", "exact": true }, { "start": 5.583, "end": 6.653, "text": "uh,", "exact": true }, { "start": 8.573, "end": 9.615, "text": "That is all for now.", "exact": true }], "removedSec": 3.38, "newDurationSec": 7, "text": "Hello and welcome to this demo. Today we will open the Settings page. then we click save." }
  3. cut_by_transcript { …the same, without dryRun }One select/aselect pass: each kept frame moves back by the time cut before it, so audio and video stay the same length.{ "outputPath": "cut-transcript-….mp4", "srtPath": "cut-transcript-….srt", "removedSec": 3.38 }
  4. burn_subtitles { "input": "cut-transcript-….mp4", "subtitles": "cut-transcript-….srt" }The re-timed SRT matches the cut video, so captions land on the right words.
00:30THE OUTPUT

Transcribing the cut video again gives back "Hello and welcome to this demo. Today we will open the settings page, then we click Save.": the fillers and the last line are gone and nothing else was clipped.

Whisper often leaves fillers out of its transcript, and only what the transcript contains can be cut. With sentence-level cues, fillers: true skips a filler inside a sentence rather than guess its time, and says how many it kept.
